# Spark Platform

> Spark Platform is the MLS data platform built by FBS, a 100% employee-owned company in Fargo,
> North Dakota that operates the Flexmls MLS system for more than 120 MLS organizations. Spark
> exposes MLS content to third-party developers through two interfaces: the proprietary Spark
> API (SparkQL filtering over listings, contacts, saved searches, market statistics and
> portals) and a RESO Web API (OData) implementation serving the RESO Data Dictionary. FBS is a
> RESO Certified technology provider (UOI T00000052, "Certified Current"). The documentation is
> fully public and unusually complete; the data is not. Every data endpoint — including the
> OData $metadata document — returns HTTP 401 without an MLS-approved key, and real data
> requires a signed FBS Developer Agreement plus an MLS-approved data plan at USD 50/month per
> MLS.

Provenance: generated 2026-07-26 by the API Evangelist enrichment pipeline from
https://github.com/api-evangelist/spark-platform (apis.yml + harvested artifacts). FBS does not
publish an llms.txt (https://sparkplatform.com/llms.txt returns 404), and
https://sparkplatform.com/robots.txt disallows every named AI crawler — treat the links below
as pointers for a human or a licensed integration, not as a crawl list.

## APIs

- [Spark API](https://sparkplatform.com/docs/overview/api): Proprietary REST API over Flexmls
  MLS content. Base URL https://sparkapi.com/v1 (read/bulk traffic:
  https://replication.sparkapi.com/v1). Listings and their photos, videos, virtual tours,
  documents, floor plans, rooms, units, history and rules; contacts; saved searches; listing
  carts; portals/VOW accounts; market statistics; overlays; standard and custom field metadata;
  system info; developer key/role/domain/usage administration. Filtering uses SparkQL.
- [Spark RESO Web API](https://sparkplatform.com/docs/reso/overview): RESO Web API
  implementation as an OData service at
  https://replication.sparkapi.com/Version/3/Reso/OData/. Resources: Property, Member, Office,
  Media, OpenHouse, Room, Unit, GreenVerification, PowerProduction, Lookup, Teams.
- [Spark Webhooks](https://sparkplatform.com/docs/webhooks/webhooks): Outbound RESO Entity
  Event deliveries for Property, Member and Office changes, HMAC-SHA256 signed, 3 retries,
  ~2s response timeout, catch-up replay. FBS holds the RESO webhooks 1.0.0 endorsement.

  the vendor's public collection, 64 real requests across both surfaces.
- OpenAPI/Swagger: none published. Probes of /openapi.json, /openapi.yaml, /swagger.json,
  /v1/openapi.json, /api-docs on sparkapi.com, replication.sparkapi.com and sparkplatform.com
  all returned 404 on 2026-07-26.
- OData $metadata: https://replication.sparkapi.com/Version/3/Reso/OData/$metadata — HTTP 401
  anonymously; the schema cannot be read before signing.
